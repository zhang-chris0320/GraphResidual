# Checkpoints

No checkpoint is committed to public Git history by default. The archived Graph-Residual ESM2 V2 checkpoint was loadable and approximately 5.9 MB, but model artifacts should be published through a model registry such as Hugging Face with a license, checksum, and versioned card.

To use a local checkpoint, pass its path to scripts/export_embeddings.py. Keep checkpoint files outside Git unless they have been explicitly reviewed and added with a documented provenance record.
